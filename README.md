# House Price Prediction

**Recommended Use:** Regression Models  
**Domain:** Real Estate  
**Dataset:** [UCI Real Estate Valuation](https://archive.ics.uci.edu/dataset/477/real+estate+valuation)

## 📋 Project Overview

This project predicts the house price per unit area (10,000 NTD/Ping) in Sindian District, New Taipei City, Taiwan.

- **Instances:** 414
- **Features:** 6 (transaction date, house age, distance to MRT, convenience stores, latitude, longitude)
- **Target:** House price of unit area (continuous)
- **Task:** Regression
- **Missing Values:** None
